# Moramarket

Moramarket is a self-hosted multi-vendor marketplace for physical products, digital products, and services.

**Version:** 0.0.1 (development)
**Author:** Ton Samith — https://tonsamith.com
**Project:** https://moramarket.tonsamith.com
**Framework:** Laravel 13, Tailwind CSS
**License:** Proprietary commercial software; third-party packages retain their individual licenses.

This repository starts as a real Laravel application. Marketplace functionality is implemented in milestones. Do not deploy to production until installation, security, payments, and release acceptance checks pass.

The repository is publicly visible; private commercial source should be moved to a private repository before distribution if secrecy is desired.
