# Moramarket Release Milestones

## Implemented in development

1. Laravel 13 foundation, role-aware dashboards, public storefront, product management and stock-locked physical-goods COD orders.
2. Secure five-step browser installer for prepared release assets, first-admin provisioning and MySQL testing.
3. Appearance, general settings and system health.
4. Private Media Library for images/video, reusable featured image picker and owner access.
5. Page/Post Manager, sanitized HTML editor, SEO, publish/draft, revision snapshots and restore.
6. Policy Center, Knowledge Base and customer/admin support-ticket workflows.
7. Flat vendor delivery fees, free threshold, per-vendor checkout breakdown and delivery tracking workflow.

## Before release

- Confirm green CI and perform real-browser visual and accessibility acceptance on mobile, tablet and desktop.
- Prepare and independently install/upgrade a complete package on cPanel and aaPanel; test failed-install recovery and backups.
- Complete shipping zones/tax compliance, returns/refunds, invoices and financial reconciliation.
- Implement provider-verified payment gateways only where legally eligible; secure digital entitlement vault and service fulfillment.
- Expand rich media, content/page builder, 13-language translations and editorial workflows.
- Add SMTP delivery, notifications, support ticket SLA controls, full policy/legal review and role audit trails.
- Complete license verification, verified updater/rollback, clean customer docs and CodeCanyon product review.

The GitHub Main branch is development only. Live deployment remains separate. No genuine financial transaction gateway is enabled.
